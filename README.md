# Campus Sharing Hub — MVP with Supabase

เว็บเช่าของใช้ระยะสั้นสำหรับนักศึกษา พัฒนาต่อจากหน้าเดิมด้วย Vite + JavaScript + Supabase

## ฟีเจอร์ในเวอร์ชันนี้

1. สมัครสมาชิก / เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
2. ลงประกาศสินค้าจริง เก็บลง PostgreSQL และแสดงให้ผู้ใช้คนอื่นค้นหาได้
3. ค้นหาด้วยคำ หมวดหมู่ งบประมาณ และเรียงราคา
4. ส่งคำขอจองพร้อมวันรับ–คืน จุดนัดรับ และหมายเหตุ
5. เจ้าของประกาศอนุมัติหรือปฏิเสธคำขอจองได้ และมีการป้องกันวันจองที่ทับซ้อนกันเมื่ออนุมัติ
6. หน้าบัญชีของฉัน แสดงประกาศของฉัน รายการที่ฉันจอง และคำขอที่ได้รับ พร้อมซ่อน/เปิดประกาศและยกเลิกคำขอที่ยังรออนุมัติ

ฟีเจอร์ยังไม่รวมการชำระเงินจริง/มัดจำออนไลน์ แชตเรียลไทม์ การอัปโหลดรูปเข้า Storage การยืนยันนักศึกษาแบบอัตโนมัติ หรือกระบวนการจัดการข้อพิพาท

## ความต้องการก่อนเริ่ม

- Node.js รุ่น LTS (มาพร้อม npm)
- บัญชี Supabase และโปรเจกต์หนึ่งรายการ
- อินเทอร์เน็ตเพื่อดาวน์โหลด dependencies

## A. สร้างฐานข้อมูล Supabase

1. เปิด https://supabase.com/ แล้วสร้างโปรเจกต์ใหม่
2. ใน Dashboard เข้า **SQL Editor → New query**
3. เปิดไฟล์ `supabase/schema.sql` จากโฟลเดอร์นี้ คัดลอกเนื้อหาทั้งหมดไปวางใน SQL Editor แล้วกด **Run**
4. ตรวจว่าไม่มี error และมีตาราง `profiles`, `listings`, `bookings` ใน Table Editor

SQL สร้าง Row Level Security (RLS), สร้าง profile หลังสมัครสมาชิก, คำนวณค่าเช่าที่ฝั่งฐานข้อมูล และจำกัดให้เฉพาะเจ้าของประกาศอนุมัติ/ปฏิเสธคำขอจองได้

## B. ตั้งค่า URL และ key ให้เว็บไซต์

1. ใน Supabase เปิด **Project Settings → API** (บางหน้าจออาจแสดง Project URL กับ API keys แยกตำแหน่ง)
2. คัดลอก **Project URL** และ **anon/public key** หรือ **publishable key** เท่านั้น
3. คัดลอก `.env.example` ในโฟลเดอร์โปรเจกต์แล้วตั้งชื่อสำเนาเป็น `.env.local`
4. แก้ `.env.local` เป็นลักษณะนี้ โดยแทนค่าตัวอย่างด้วยค่าจากโปรเจกต์ของคุณ:

   ```dotenv
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-or-publishable-key
   ```

   ห้ามใส่ `service_role` หรือ secret key ในเว็บไซต์ฝั่งหน้าเว็บ และห้ามส่ง key ประเภทนั้นให้ใคร

## C. เปิดเว็บไซต์บน Windows

เปิด CMD/Terminal ในโฟลเดอร์เดียวกับ `package.json` และ `index.html` จากนั้นรัน:

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง (ปกติ `http://localhost:5173`). หากเปลี่ยน `.env.local` ขณะเซิร์ฟเวอร์กำลังทำงาน ให้หยุดด้วย `Ctrl+C` แล้วรัน `npm run dev` ใหม่

ตรวจสอบว่ากล่องแจ้งสถานะบนเว็บบอกว่าเชื่อมต่อโหมดฐานข้อมูลแล้ว ไม่ใช่โหมดตัวอย่าง

## D. ตั้งค่าการยืนยันอีเมล

ถ้า Supabase ตั้งให้ต้องยืนยันอีเมล การสมัครจะส่งอีเมลให้กดลิงก์ก่อนจึงเข้าสู่ระบบได้ ใน Supabase ไปที่ **Authentication → URL Configuration** แล้วเพิ่ม `http://localhost:5173` ในรายการ Redirect URLs (ถ้ามีหน้าการยืนยันอีเมล ให้ทดสอบด้วยอีเมลที่คุณเข้าถึงได้)

สำหรับการทดสอบบนเครื่องเดียว สามารถใช้ผู้สมัครสองบัญชีที่แยกกัน: บัญชี A ลงประกาศ แล้วบัญชี B ส่งคำขอจอง จากนั้นกลับเข้าบัญชี A → **บัญชีของฉัน → คำขอที่ได้รับ** → อนุมัติหรือปฏิเสธ

## ข้อจำกัดและข้อควรระวัง

- URL/key ยังไม่ได้เชื่อมกับบัญชี Supabase ของผู้ใช้โดยอัตโนมัติ ต้องใส่ใน `.env.local` เอง
- `anon/public` key เป็นค่าที่ใช้งานใน frontend ได้เมื่อเปิด RLS ถูกต้อง แต่ห้ามใช้ `service_role`/secret key ในไฟล์ frontend
- รูปภาพในเวอร์ชันนี้ใช้ URL สาธารณะ ยังไม่มีระบบอัปโหลดรูปภาพของผู้ใช้
- ราคาที่แสดงเป็นค่าเช่าเท่านั้น ไม่มีการตัดเงิน/รับเงินจริง
- คำขอที่รออนุมัติยังไม่ล็อกช่วงวัน เจ้าของต้องอนุมัติเพียงคำขอเดียวต่อรายการ/ช่วงวันที่; PostgreSQL จะป้องกันคำขอที่อนุมัติแล้วทับซ้อนกัน
- ก่อนเปิดให้ใช้งานสาธารณะ ควรทดสอบ auth, RLS, นโยบายการคืนของ, การรายงานปัญหา และแผนรับมือความเสียหายอย่างจริงจัง

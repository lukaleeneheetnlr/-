# Campus Sharing Hub — เว็บต้นแบบแบบใช้ npm

เว็บต้นแบบภาษาไทยสำหรับทดลองแนวคิดตลาดเช่า-ยืมของใช้ระยะสั้นในมหาวิทยาลัย ใช้ HTML, CSS, JavaScript และ Vite เป็น development server เพื่อให้เปิดผ่าน `npm run dev` ได้

## สิ่งที่ต้องมี

- Node.js รุ่น 18 ขึ้นไป (แนะนำติดตั้ง Node.js รุ่น LTS)
- npm ซึ่งติดตั้งมาพร้อม Node.js
- อินเทอร์เน็ตสำหรับติดตั้ง Vite ครั้งแรก

## วิธีติดตั้งและเปิดเว็บบน Windows

1. ดาวน์โหลด ZIP และแตกไฟล์
2. เปิด CMD หรือ Terminal ในโฟลเดอร์เดียวกับ `package.json` และ `index.html`
3. ตรวจสอบว่าอยู่ถูกโฟลเดอร์ด้วยคำสั่ง `dir` ต้องเห็นไฟล์ `package.json` และ `index.html`
4. ติดตั้ง dependencies:

   ```bash
   npm install
   ```

5. เปิด development server:

   ```bash
   npm run dev
   ```

6. Vite จะแสดง URL ในหน้าจอ โดยปกติคือ `http://localhost:5173/` ให้เปิด URL นั้นใน Chrome หรือ Edge
7. หยุดเซิร์ฟเวอร์ด้วย `Ctrl + C`

> สำคัญ: อย่ารัน `npm install` หรือ `npm run dev` ในโฟลเดอร์แม่ที่ไม่มี `package.json` ให้ `cd` เข้าโฟลเดอร์ `campus-sharing-hub` ก่อน หรือเปิด Terminal ผ่าน VS Code ในโฟลเดอร์ที่มีไฟล์นี้

## คำสั่งอื่น

```bash
npm run build
npm run preview
```

`npm run build` สร้างไฟล์ production ลงใน `dist/` ส่วน `npm run preview` ใช้ดูตัว build ในเครื่อง

## ฟีเจอร์ต้นแบบ

- responsive รองรับจอมือถือและเดสก์ท็อป
- ค้นหาชื่อหรือรายละเอียดสินค้า
- กรองหมวดหมู่และงบประมาณต่อวัน
- เรียงราคา
- บันทึกรายการโปรด
- ดูรายละเอียด สภาพของ เงินมัดจำ และจุดนัดรับ
- ส่งคำขอจองจำลอง เลือกวันรับ-คืน และคำนวณยอดค่าเช่า
- แจ้งสิ่งที่ต้องการเช่า (Demand-first)
- ลงประกาศของใหม่จากฟอร์ม
- เก็บประกาศที่เพิ่ม คำขอ และรายการโปรดใน `localStorage` ของเบราว์เซอร์เครื่องนั้น

## ข้อจำกัด

- รายการเริ่มต้นเป็นข้อมูลตัวอย่าง
- ไม่มีระบบสมัครสมาชิกหรือยืนยันตัวตนจริง
- ไม่มีฐานข้อมูลกลาง; `localStorage` ใช้ได้เฉพาะ browser/profile เครื่องที่บันทึก
- คำขอจองไม่ได้ส่งไปหาเจ้าของจริง และไม่มีการตรวจวันว่างแบบ server-side
- ไม่มีการรับชำระเงินจริง ไม่มีระบบพักเงิน/คืนเงิน และไม่มีประกันของหาย
- อย่ากรอกข้อมูลส่วนบุคคลจริงในเดโมนี้
- รูปภาพบางส่วนโหลดจาก Unsplash ต้องใช้อินเทอร์เน็ต

## แนวทางพัฒนาต่อ

ก่อนเปิดใช้จริง ควรสร้าง backend/API และฐานข้อมูล PostgreSQL, ระบบบัญชีผู้ใช้, การตรวจปฏิทินจองบน server, การจัดการข้อพิพาท และใช้ผู้ให้บริการชำระเงินที่เหมาะสม โดยไม่เก็บข้อมูลบัตรชำระเงินเอง

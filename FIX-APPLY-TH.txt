Campus Sharing Hub — แก้ปุ่มล็อกอินและเลย์เอาต์หน้าจอ

ไฟล์ที่เปลี่ยน:
- index.html: เพิ่มกฎ [hidden] { display:none !important } เพื่อให้ปุ่มเข้าสู่ระบบซ่อนจริงหลังล็อกอิน และปรับระยะ/ขนาดแถบเมนูสำหรับเดสก์ท็อป แท็บเล็ต และมือถือ
- src/main.js: เมนูมือถือเปลี่ยนตามสถานะล็อกอิน ผู้ที่ล็อกอินแล้วจะเห็นบัญชีของฉัน/แผงควบคุมแอดมินและออกจากระบบ แทนปุ่มเข้าสู่ระบบ/สมัครสมาชิก

วิธีนำไปใช้โดยไม่ทับไฟล์ตั้งค่า:
1. แตก ZIP ไว้ในโฟลเดอร์ชั่วคราว
2. คัดลอก index.html ไปแทนไฟล์เดิมในโฟลเดอร์โปรเจกต์
3. คัดลอก src/main.js ไปแทนไฟล์เดิมในโฟลเดอร์ src
4. อย่าลบ .env.local หรือค่า Environment Variables ใน Vercel
5. เปิด CMD ที่โฟลเดอร์โปรเจกต์จริง แล้วรัน:
   npm run build
   npx vercel --prod
6. หลัง deploy เสร็จ เปิดเว็บแล้วกด Ctrl+F5 เพื่อโหลดไฟล์ใหม่

การตรวจสอบในสภาพแวดล้อมนี้:
- ตรวจไวยากรณ์ JavaScript ด้วย node --check ผ่าน
- ไม่สามารถยืนยัน Vite build ได้ เนื่องจาก npm install หมดเวลาระหว่างติดตั้ง dependencies
